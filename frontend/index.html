    AlphaLens: An Explainable Multimodal Quantitative ML Framework

    Quantitative Machine Learning Research Release

    System Philosophy

    AlphaLens operates under the fundamental thesis that machine learning delivers maximal value in financial decision making when functioning as an evidence-based probability and risk engine rather than an overt chatbot interface. By combining technical momentum, FinBERT financial NLP sentiment, fundamental ratios, and Gaussian Mixture Model (GMM) market regime clustering under strict walk-forward cross-validation (zero lookahead leakage), AlphaLens produces well-calibrated probability distributions with transparent causal feature attributions.

    Mathematical Ensemble Architecture

    • Soft-Voting Calibrated Ensemble: HistGradientBoosting + Random Forest + Logistic Regression with Platt Sigmoid calibration: $\hat{P}(y=1 \mid \mathbf{x}) = \frac{1}{1 + \exp(A \cdot f(\mathbf{x}) + B)}$.
    • Quantile Return Bands: 10th, 50th, and 90th percentile regressors optimizing pinball loss for empirical bounds.
    • Causal Attribution Engine: Dynamic multi-factor decomposition answering "Why is it moving?" and "What changed since yesterday?".
